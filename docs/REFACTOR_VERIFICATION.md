- توحيد قالب التدريبات، مع الاحتفاظ بعناوين وتعليمات الدروس الأصلية في `exercisePresentation` لكل درس.
- الحفاظ على معنى وترتيب كل رمز وكل كلمة وسؤال وإجابة، ومعرفات وروابط التنقل.
- اشتقاق مرشحات الكتابة وأعداد الأسئلة من البيانات؛ شكل المرشحات الثلاثة الحالية كما كان.
- الحفاظ على React 18.3.1 وReactDOM 18.3.1، مع نقلهما من CDN إلى ملفات محلية مثبتة الإصدار.
- إبقاء Tailwind CDN والخطوط وطريقة التنسيق الحالية دون ترحيلها في هذه الخطوة.
- أداة Babel بنفس الإصدار السابق 7.26.9 تعمل وقت البناء، ولا يحملها الزائر.

## فحوص قابلة للإعادة

`npm test` يحمي المحتوى المرجعي للدروس الثلاثة، ويختبر محلل ترتيب الرموز واتجاه البحث وتجميع أربعين درسًا تجريبيًا في الذاكرة.
`npm run check` يتحقق من المعرفات والروابط ومن أن مخرجات التشغيل توافق المصادر.
`npm run check -- --content-baseline` يقارن مجموع البيانات بالمرجع الأصلي؛ هذا الفحص الإضافي مخصص لفترة التنظيم، وسيتغير مجموع البيانات عند إضافة دروس فعلية.

البصمات المرجعية في `tests/fixtures/refactor-baseline.json`؛ بصمات وحدات الكود فيه تسجّل مرحلة الاستخراج فقط، ولا تمنع تحديثها المقصود في المرحلة الثانية.
هذه الفحوص تؤكد حفظ المحتوى والسلوك المحدد، ولا تعني تدقيقًا أكاديميًا جديدًا للمادة أو ضمانًا لغياب كل خطأ محتمل.

## نتائج المراجعة النهائية المحلية

- سبعة اختبارات آلية ناجحة، تشمل منع المعرفات المكررة وروابط القواعد المفقودة وأنواع التدريبات غير المدعومة.
- مقارنات نصية للدروس الثلاثة في التدريبات متطابقة، وعدد لوحات الرسم ومعرفات القفزات متطابق.
- كشف إجابات القراءة، وقبول إجابة الكتابة `m pt` مع مسافات زائدة، وبدء الاختبار وحساب الدرجة والانتقال للسؤال التالي تعمل.
- الكلمات الـ69 داخل إطاراتها عند 320 و390 و768 و1280 بكسل، دون تجاوز أفقي للصفحة.
- قائمة المحتوى على الموبايل بقيت داخل الشاشة، وفتحت قاعدة في الدرس الثالث وهو مطوي ثم نقلت العنوان إلى أسفل الشريط.
- سجل أخطاء تشغيل النسخة المنظمة كان خاليًا أثناء الفحص النهائي المحلي.

هذه نتائج محلية قبل النشر؛ يجب التحقق من الموقع العام بعد رفع ملفات البناء.
