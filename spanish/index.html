💡 قواعد النطق السريع للغة الإسبانية

اللغة الإسبانية تُقرأ كما تُكتب وفق القواعد الصوتية التالية (الشرح بالعربي يميناً والمثال بالإسباني يساراً):

1. الحروف المتحركة الخمسة: تُنطق واضحة دائماً (آ - إيه - إي - أو - أو مضمومة)
A - E - I - O - U
2. حرف H صامت لا يُنطق: (أوتيل / أبيتاسيون / إيبوستيلا)
Hotel / Habitación
3. حرف J يُنطق (خ) دائماً: (خوليو / إيخي / باخورّيلييفي)
Julio / Eje / Bajorrelieve
4. حرفا LL يُنطقان (ي): (بايي / يامو)
Valle / Llamo
5. مقطع QU يُنطق (ك): حرف u لا يُنطق (كي / كييري)
Qué / Quiere
6. حرف Ñ يُنطق (ني): (بانيو = حمام / إسبانيول)
Baño / Español
7. علامة المد (á, é, í, ó, ú): توضح موضع التشديد في النطق وتميز أدوات الاستفهام
Pirámide / Sarcófago
